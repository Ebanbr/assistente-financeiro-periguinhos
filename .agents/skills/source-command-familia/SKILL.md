# source-command-familia

Use this skill when the user asks to run the migrated source command `familia`.

## Command Template

Leia o arquivo `AGENTS.md` na raiz deste projeto e me dê, em português (pt-BR),
um resumo curto de:
1. O que é o projeto (1 linha).
2. Estado atual (último commit + o que está saudável).
3. Pendências em aberto que dependem de decisão minha.

Depois pergunte por onde eu quero continuar. Não altere nenhum código ainda.
